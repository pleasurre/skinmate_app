# 로그인·브랜드·홈·탐색 수정

2026-09-23 요청 반영.

- 새 앱 문서를 열거나 새로고침하면 기존 체험 로그인 기록과 무관하게 로그인 화면부터 시작한다. 로그인 버튼은 매번 온보딩으로 연결된다. 앱 내 화면 전환은 세션을 유지한다.
- 온보딩 완료 후 새 관심사와 지역을 적용한다. 이전 추천의 activeConcern은 해제한다. 기존 찜·후기는 삭제하지 않는다.
- i는 점 없는 글자와 해당 글자에 고정한 주황 점을 조합한다. m 하단 곡선도 m을 기준으로 em 단위 고정해 크기에 따라 같이 움직인다.
- 홈 헤더를 Hero 내부로 옮겨 같은 인물 이미지가 상단까지 이어진다. 짙은 청록·네이비 그라데이션과 가장자리 음영을 적용했다. 사진은 기존 Unsplash 인물로, 첨부 시안의 인물 원본과 다르다.
- 탐색 대분류는 높이 약 45px의 한 줄 가로 스크롤 영역으로 변경. 세부 카테고리는 대분류를 선택한 경우에만 표시한다. 터치 스와이프·트랙패드·마우스 드래그를 지원한다.

검증: 기존 로그인 기록이 있어도 첫 진입 로그인 표시, 로그인 → 5단계 온보딩 → 홈, 탐색 후 새로고침 시 로그인 복귀를 실제 브라우저에서 확인. 대분류 컨테이너 폭 366px, 콘텐츠 폭 593px로 수평 스크롤 가능. decision-flow / onboarding / personalization 회귀 검사 통과. 로그인은 실제 OAuth 가입이 아닌 명시된 포트폴리오 체험이다.
